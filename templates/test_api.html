Endpoints Disponibles

GET
/api/cv

Récupère toutes les données du CV au format JSON (expériences, formations, compétences, projets, etc.)

GET
/api/contact

Récupère uniquement les informations de contact (nom, email, téléphone, LinkedIn, GitHub)

GET
/api/reload

Recharge les données du CV depuis le fichier cv_data.json. Utile après avoir modifié les données.

💡 Comment utiliser ces API

Ces endpoints peuvent être appelés depuis n'importe quelle application (JavaScript, Python, etc.) pour récupérer dynamiquement les données du CV. Exemple d'utilisation en JavaScript : 

// Récupérer les données du CV
fetch('/api/cv')
  .then(response => response.json())
  .then(data => {
    console.log(data);
    // Utiliser les données...
  });
